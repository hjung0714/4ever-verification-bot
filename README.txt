4ever 인증 봇

기능
- /인증패널 : 추천 / 후기 / 이벤트 / 구매 인증 패널 생성
- 추천 인증 : 사진 필수, 관리자 승인 시 +1 코인
- 후기 작성 인증 : 사진 필수, 관리자 승인 시 +1 코인
- 이벤트 참여 인증 : 사진 필수, 관리자 승인 시 +1 코인
- /초대인증 @멤버 : 초대받은 새 멤버를 멘션한 뒤 제출하기를 누르면 자동 인증, +2 코인
- 구매 인증 : /직접구매 또는 패널에서 코인 갯수 + 원하는 제작물 제출, 관리자 승인/반려
- 반려 시 사유 입력 필수
- /내코인 : 현재 코인 확인
- 코인과 인증 기록 JSON 저장
- Railway Volume 연결 시 재시작 후에도 데이터 유지

명령어
/인증패널
/인증설정
/인증설정확인
/초대인증
/내코인
/직접구매

환경변수
DISCORD_TOKEN
OWNER_ID
GUILD_ID (선택)

requirements.txt는 discord.py 2.7+ 기준입니다.
